# 5人に通す

`personas.md` の5人で、変更後の画面をレビューする。**人物像の再現が目的ではない。
5人ぶんの判定基準を、画面の実物に当てて落ちを見つけるための手順。**

## 手順

1. **`personas.md` を読む。** 5人と、それぞれの「判定」を頭に入れる。
   ファイルが唯一の出どころ。ここに書き足したいことができたら `personas.md` を直す。

2. **実物を見る。** 記憶や差分ではなく、動かした画面で見る。

   ```sh
   python3 -m http.server 8000   # → http://localhost:8000/
   ```

   最低限、次の3つの状態を見る。
   - 既定（育休1か月）／スライダーを動かした状態（6か月など）
   - 畳んである `details` を開いた状態
   - スマホ幅（390px）とダークモード

3. **1人ずつ、その人の判定だけを見る。** 5人の視点を混ぜない。
   混ぜると「だいたい良さそう」に落ち着いて、誰の問題も見つからない。

4. **落ちた項目をそのまま書く。** 直せるかどうかは後で考える。
   「これは仕方ない」を先に混ぜない。

5. **報告は3つに分ける。**
   - 通った項目（数だけでよい）
   - 落ちて**直した**もの（何をどう直したか）
   - 落ちたが**直していない**もの（なぜ直さないか。次に何を決めれば直せるか）

## やらないこと

- **5人を増やさない。** 増やすと「誰にでも当てはまる画面」を作りにいってしまう。
- **人物の設定を膨らませない。** 判定に効かない属性は書かない。
- **落ちた項目を勝手に握りつぶさない。** 直さない判断は残す。
