# やすめる — デザインの決めごと

> `ui-ux-pro-max` スキルの `--design-system` が出したものを土台に、
> **この画面の実装に合わせて書き直したもの**です。
> 生成そのままの値は残していません（残すと、次に触る人が実装と食い違うほうを信じてしまう）。
>
> ページ個別の決めごとは `design-system/yasumeru/pages/<page>.md` に置き、
> あればそちらがこのファイルより優先します。いまは1画面しかないので置いていません。

- **生成日**: 2026-08-18（`--variance 3 --motion 2 --density 4`）
- **カテゴリ**: Government / Public Service
- **スタック**: 素の HTML + CSS + ES モジュール。フレームワークもビルドもなし
- **スタイル**: Minimalism & Swiss Style（生成結果のまま採用）

## スキルの推奨から外したもの

| 推奨 | 採否 | 理由 |
|---|---|---|
| 配色 `#0F172A` / `#0369A1` 系 | **不採用** | いまの系列色は `dataviz` スキルの検証でライト／ダーク両モードとも全項目 pass 済み。汎用パレットに差し替えると、グラフの識別性を作り直すことになる |
| 本文フォント Atkinson Hyperlegible | **不採用** | 日本語のグリフを持たない。指定しても全文字がフォールバックするので、体裁だけ増えて中身が変わらない。`system-ui` から始まる既存のスタックを使う |
| GSAP の Scroll Reveal | **不採用** | 外部への通信をゼロにしている（依存を足さない）。それ以前に、結果は開いた時点で出ているべきで、スクロールで出す理由がない |
| 「Single CTA focus」のページ構成 | **不採用** | 何かを申し込ませる画面ではない。CTA は置かない |
| ボタン・カード・モーダルの雛形 CSS | **不採用** | モーダルは使わない。カードのホバーで浮かせる演出も、読むための画面には要らない |
| アンチパターンと Pre-Delivery Checklist | **採用** | 下に残してある |

## 色

値は `style.css` の `:root` が唯一の出どころ。ここは写しなので、**変えるときは CSS のほうを直す。**

| 役割 | ライト | ダーク | 使いどころ |
|---|---|---|---|
| `--surface-0` | `#f4f4f2` | `#121211` | ページの地 |
| `--surface-1` | `#fcfcfb` | `#1a1a19` | パネル・チャートの面 |
| `--surface-2` | `#ececea` | `#232322` | 表のヘッダ |
| `--border` / `--border-strong` | `#d8d8d4` / `#b9b9b3` | `#34342f` / `#4b4b45` | 罫線・入力欄の枠 |
| `--text-primary` | `#0b0b0b` | `#ffffff` | 本文・数字 |
| `--text-secondary` | `#52514e` | `#c3c2b7` | 補足 |
| `--text-muted` | `#6b6a63` | `#9a998f` | 出典・但し書き |
| `--link` | `#1f68c4` | `#4d94ea` | **文字として置く青** |
| `--series-1` | `#2a78d6` | `#3987e5` | 育休を取る／線と面 |
| `--series-2` | `#eb6834` | `#d95926` | 取らない |
| `--series-3` | `#1baf7a` | `#199e70` | 人ごとの色（二人目） |

**`--link` と `--series-1` を分けてある。** `--series-1` は線と面のための色で、
明るい地の上では小さい文字に足りない（`#2a78d6` on `#f4f4f2` は 4.01:1）。
**リンク・小見出し・ワードマークは `--link`**、グラフの線と塗りは `--series-1`。

`--text-muted` は以前 `#77766f` で、明るい地で 4.1〜4.4:1 しかなかった。
出典と但し書きが全部これなので `#6b6a63`（4.6〜5.3:1）に落としてある。

コントラストの下限：**本文・小さい文字は 4.5:1、グラフの線と面は 3:1。**
色を足すときは両モードで測ってから入れる。

## 文字

```css
font-family: system-ui, -apple-system, "Hiragino Sans", "Noto Sans JP", sans-serif;
```

Web フォントは読み込まない（外部への通信をゼロにしている）。

| | 値 |
|---|---|
| 本文 | `16px` / `line-height: 1.75` |
| h1 | `clamp(1.35rem, 5.6vw, 1.9rem)` |
| h2 | `1.05rem` |
| 補足（`.note`） | `.875rem` |
| 但し書き（`.fine`） | `.75rem` |
| 数字 | `font-variant-numeric: tabular-nums` を必ず付ける |

**`.72rem` 未満は使わない。** 金額は全て `tabular-nums`（桁が揃わないと比べられない）。

---

## 余白と角

`--radius: 10px`（パネル）／ 8px（カード・入力欄）／ 6px（小さい箱）／ 999px（目次のチップ）。
`--maxw: 860px`。余白は `.25 / .5 / .75 / 1 / 1.25rem` の刻みで、
Density 4（Standard）にあたる。新しい値を足さない。

影は使わない（Swiss Style の「sharp shadows if any」を、罫線だけで通す側に倒している）。
例外はスライダーのつまみだけ。

---

## 当たり判定

WCAG 2.2 の Target Size (Minimum) は 24 CSS px、iOS は 44pt、Android は 48dp。
**この画面はスマホで読まれる前提なので、44px に寄せる。**

| もの | 大きさ |
|---|---|
| チェックボックス | 24×24（行は `min-height: 44px`） |
| スライダー | つまみ 26px／当たり判定の高さ 44px |
| `summary` | `min-height: 44px` |
| ボタン | `min-height: 44px` |
| 目次のチップ | `min-height: 36px` + 8px 以上の間隔 |

本文の中のインラインリンクは例外（WCAG の inline exception）。

## 動き

**Motion 2/10（Subtle）。** 使ってよいのは 150〜250ms の色と不透明度だけ。
位置や大きさは動かさない。`prefers-reduced-motion: reduce` で全部止める。

スクロールで出す演出は入れない。**結果は開いた時点で出ている。**

---

## この画面に固有の決めごと

1. **動かせるのは父の育休の月数だけ。** その1つを、入力欄と画面の底の2か所から触れるようにしてある（`.sticky-bar`）。片方を消すときはもう片方も見直す。
2. **底のバーに差額を出さない。** 出すのは手取り。「差額を入口にしない」という README の線と揃える。
3. **数字は入れた場所のそばで返す。** 金額の入力には万円（`.echo`）、スライダーには結果（`.slider-echo`）。
4. **ツールチップはホバー専用にしない。** タップでも出す（`bindTip`）。当たり判定は `touch-action: pan-y` で、縦のスワイプはページに渡す。
5. **入力で書き換わる数字は `#live-status` にも一文で渡す。** 数字だけを読み上げても意味にならない。
6. **畳んだものは印刷前に開く。** 相手や勤務先と見るために刷ることがある。
7. **アイコンに絵文字を使わない。** いまは SVG も持ち込んでいない（色と罫線だけで通している）。

## アンチパターン（使わない）

- ❌ 飾りの多い装飾
- ❌ 低いコントラスト
- ❌ 演出のための動き
- ❌ AI っぽい紫〜ピンクのグラデーション
- ❌ 絵文字をアイコンにする（使うなら SVG を1つの組から）
- ❌ 押せるのに `cursor: pointer` がない
- ❌ ホバーでレイアウトがずれる
- ❌ フォーカスの枠が見えない
- ❌ 色だけで意味を伝える（凡例とラベルを必ず添える）
